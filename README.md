# Tableau vivant

Application web pour animer une image a partir d'une description.

## Utilisation immediate (sans GitHub Pages)

1. Ouvrez ce depot: https://github.com/urdirditfurd/tableau-vivant
2. Cliquez le fichier **index.html**
3. Bouton **Download raw file** (icone telecharger)
4. Double-cliquez le fichier telecharge

Le fichier est autonome: CSS et JavaScript sont inclus. Pas besoin des autres fichiers pour l'utiliser.

## GitHub Pages (site en ligne)

1. Allez sur https://github.com/urdirditfurd/tableau-vivant/settings/pages
2. Source: **Deploy from a branch**
3. Branch: **main** / dossier **/ (root)**
4. Save
5. Site: https://urdirditfurd.github.io/tableau-vivant/

Important: ouvrir le HTML dans l'onglet Code de GitHub n'execute PAS l'application (GitHub affiche le code source seulement).
